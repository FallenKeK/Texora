# Texora (ранее WordLike): архитектура и решения (ноябрь 2026)

## Название
С 06.11.2026 приложение называется **Texora** (решение пользователя). WordLike — прежнее рабочее имя.
Установщик Texora сам убирает следы WordLike (ярлыки, реестр, папку); недавние файлы переносятся.
С 1.3.4 и Go-модуль называется `texora` (раньше `wordlike`); строки WordLike в wininstall.go и texora.go оставлены намеренно — это перенос со старой версии.

## Текущий курс (с 06.11.2026): полностью нативное приложение на Go
Решение пользователя: всё своё, без Edge и без чужих зависимостей, современный вид.
- Go, только стандартная библиотека, user32/gdi32/dwmapi/comdlg32/shell32 через syscall (без cgo), кросс-компиляция с Linux.
- Ресурсы exe (значок, манифест PerMonitorV2 + Common Controls 6, VERSIONINFO) — assets/app.rc → llvm-windres → rsrc_windows_amd64.syso.
  `go run . mkres` генерирует Texora.ico (плоская «T»), манифест и app.rc (версия берётся из AppVersion в ui.go, и строковая, и числовая),
  затем `cd assets && llvm-windres -c 65001 --target=pe-x86-64 -i app.rc -O coff -o ../rsrc_windows_amd64.syso`.
- Сборка релиза: `GOOS=windows GOARCH=amd64 go build -ldflags "-H windowsgui -s -w" -o Texora.exe .` (~7,8 МБ; без `-s -w` ~10,7 МБ). CI собирает так же.
- Окно без системной рамки (WM_NCCALCSIZE) с тенью, прилипанием, скруглёнными углами Win11.
- Свой растеризатор (gfx.go) в 32-битный DIB, + BlurRound (стекло) и FillPoly; буквы — GDI ClearType в тот же DIB.
  С 1.3 текст документа выводится ExtTextOutW с массивом lpDx: позиции букв берутся из вёрстки (ширины при measureK=4),
  иначе хинтинг GDI на экранном размере съедал или раздувал пробелы.
- Файлы: model.go, layout.go, paint.go, editor.go, docx/odt/rtf/doc/html/pdf.go,
  ui.go (лента, документ, команды, клавиши), texora.go (настройки, темы, вкладки, навигация), home.go (стартовый экран),
  templates.go, i18n.go + i18n2.go (английский интерфейс), widgets.go (меню, диалоги: поля text/check/select/info/custom/chips),
  icons.go, win.go + winplat.go (Windows), wininstall.go (установка).
  С 1.2: spell.go (свой движок Hunspell), hyphen.go (переносы Лианга), eq.go (формулы), review.go/review_ui.go (исправления, примечания),
  features.go/features_ui.go (оглавление, ГОСТ-библиография, формулы, обтекание, стили, регулярки).
  С 1.3: pdfobj/pdffont/pdfraster/pdfrender/pdftables.go (движок PDF), pdfview.go (вкладка-читалка), captions.go/captions_ui.go (названия и ссылки).
  С 1.4.2: pdfout.go (векторный экспорт PDF), sfnt.go (разбор TrueType/OpenType для всех ОС), fontindex.go + fontfind_windows.go
  (поиск файла шрифта по семейству), proc_*.go (жив ли процесс — для автосохранения).
  С 1.5.0: shell.go (оболочка окна: реестр команд, панель инструментов, полоса слева, инспектор, палитра Ctrl+K). Ленты больше нет.
- Словари (assets/dict/*.gz, вшиты через embed): ru_RU и en_US Hunspell + hyph_ru_RU / hyph_en_US из репозитория LibreOffice/dictionaries
  (BSD-подобные лицензии; кредиты в «О программе»). Пользовательский словарь: %APPDATA%\Texora\dict.txt.
- Настройки: %APPDATA%\Texora\settings.json (+ author, hideMarkup, noSpell, capChapter).
- Проверка на Linux: ttf.go рисует интерфейс в PNG (`go run .`), `go run . scenario`,
  `go run . features` (документ со всеми функциями 1.2 + круговое сохранение docx/odt/rtf), `go run . interactive` (18 проверок правки).
- Автотесты (с 1.3.4): `go test ./...`. eq_test.go (обмен формулами) и testdata_test.go (файлы из testdata/ открываются и сохраняются)
  идут на любой ОС, в том числе в CI на Windows (провал теста валит сборку). scenario_test.go (только не Windows: нужны шрифты ttf.go)
  оборачивает interactive, features, captions, eqtest — сценарии возвращают число провалов. RTF в счёт не идёт: он теряет новое by design.

## Модель (с 1.2)
- Разделы: Para.PF.Sect = свойства раздела, который заканчивается этим абзацем (как sectPr в Word); последний раздел — в Doc
  (Page, TitlePg, Start, Type, HF). HF = 6 историй: header/footer + .first/.even; пустая история = «как в предыдущем разделе».
  Имена историй: "header", "footer.first", для средних разделов "s<ID>/header.even". Doc.EvenOdd — глобально (как в Word).
- Вёрстка: у каждой страницы своя геометрия PageL.G (альбомные разделы), номер PageL.Num (нумерация с N), HStory/FStory.
- Поля: RField "PAGE", "NUMPAGES", "PAGEREF <закладка>", "CITE <id>[,id2] [страницы]", с 1.3 "SEQ …" и "REF …" (см. ниже).
  Номера закладок — итерация вёрстки (до 3 проходов).
- Области полей: PF.Region "toc"/"bib"/"lof:<категория>" — абзацы, сгенерированные оглавлением, списком литературы, перечнем (F9 пересобирает).
- F.Ins/F.Del — правки (id в Doc.Revs), F.Cmt — примечание (Doc.Comments), F.Lang "-" — не проверять орфографию.
- Run.Wrap/Side — плавающие картинки: square (вокруг рамки), topbottom, behind, front. REq — формула (линейная запись в духе LaTeX).
- Doc.Styles — переопределённые стили (h1..h6, Title, Subtitle, Quote, NoSpacing, TOC1..3, TOCHeading). Шаблоны ГОСТ задают стили, а не прямое форматирование.
- Отмена: снимок = Doc.Clone() целиком.

## Совместимость с Word (решения)
- Абзацы в таблицах без своих интервалов: после 0, одинарный; списки — ListParagraph + contextualSpacing; RTF — настоящие \listtable.
- docx: разделы через sectPr в pPr; headerReference default/first/even; titlePg; pgNumType start; evenAndOddHeaders, trackRevisions,
  autoHyphenation в settings (порядок элементов сверен со схемой CT_Settings).
- Оглавление — настоящее поле TOC \o "1-3" \h \z \u (fldChar через абзацы), строки = гиперссылки на закладки _Toc + PAGEREF с готовым номером, стили TOC1–3.
- Ссылки на источники — поля ADDIN TEXORA_CITE (как у Zotero: Word показывает результат «[1, с. 25]» и не трогает его);
  список литературы — ADDIN TEXORA_BIB; сами источники — w:docVar "TexoraSources" (JSON) в settings.xml.
- Формулы — OMML (m:oMath; одна в абзаце — m:oMathPara). Плавающие картинки — wp:anchor (wrapSquare/TopAndBottom/None+behindDoc).
- Примечания — comments.xml + commentRangeStart/End + commentReference; правки — w:ins/w:del (delText). Решённость примечания в docx не сохраняется.
- ODT: разделы = мастер-страницы (header-left/header-first), оглавление text:table-of-content, формулы — встроенные объекты MathML
  (annotation encoding="application/x-texora" хранит исходник), обтекание — графические стили, примечания office:annotation,
  правки text:tracked-changes, ссылки — reference-mark "TexoraCite:…", источники — meta:user-defined.
- RTF: разделы \sect\sectd (+\headerf/\headerl/\headerr), табуляции с заполнителем, \revised/\deleted, примечания \annotation;
  формулы — текстом в Юникоде. ЧТЕНИЕ RTF новых вещей не понимает (разделы, формулы и т. п.).
- Проверено: docx и odt с полным набором функций 1.2 читаются обратно без потерь; LibreOffice открывает docx/odt/rtf с тем же числом страниц,
  python-docx видит разделы/ориентацию/особую первую страницу. Формулы в LibreOffice не проверены (в среде нет модуля Math), в Word — не проверены.

## Функции 1.3 (07.11.2026): читалка PDF, формулы уровня MathType, названия и перекрёстные ссылки

### Читалка PDF (pdfobj.go, pdffont.go, pdfraster.go, pdfrender.go, pdftables.go, pdfview.go)
- Свой движок на stdlib. Разбор: xref-таблицы и потоки (Prev/XRefStm), object streams, восстановление битого xref.
  Фильтры Flate (+PNG/TIFF предикторы), LZW, AHx, A85, RunLength, DCT (image/jpeg). Шифрование RC4/AES-128/AES-256 только с пустым паролем.
- Шрифты: TrueType, CFF (в т. ч. CID), Type1 (PFB, eexec, flex, seac), Type3, Type0 Identity-H + CMap, ToUnicode, Differences, AGL с кириллицей afii.
- Растеризатор: сглаживание, nonzero/even-odd, обводки с соединениями и пунктиром, клип, картинки с масками и SMask, осевые и радиальные заливки.
- Сверено с Poppler на PDF из LibreOffice, pdflatex (Type1, TikZ), xelatex (CID TrueType, русский), ReportLab, Word. Отрисовка 13–80 мс на страницу.
- Интерфейс: PDF открывается во вкладке только для чтения. Листы рисует фоновый поток (кэш картинок, вытеснение); доступ к PdfDoc идёт под docMu.
  Есть масштаб (по ширине, страница целиком, Ctrl+колесо), PgUp/PgDn/Home/End/пробел, миниатюры, оглавление из закладок PDF и ссылки внутри файла
  (/Link GoTo, URI). Поиск идёт в фоне (Ctrl+F, F3, Shift+F3), «ё»=«е». Выделение мышью (двойной щелчок — слово, тройной — строка),
  Ctrl+C и Ctrl+A для копирования текста, печать. Сохранение и правка заблокированы.
- Нет: JPX (с 1.3.1 есть JBIG2 и CCITT), PDF с паролем на открытие, формы и аннотации кроме ссылок.

### Формулы (eq.go)
- Окружения: matrix, pmatrix, bmatrix, Bmatrix, vmatrix, Vmatrix, smallmatrix, cases (system), aligned/align/split, gathered, array{lcr}.
  Многострочный вывод можно писать без \begin: `a &= b \\ &= c`.
- Добавлено: \binom, \overset/\underset, \overbrace/\underbrace с подписью, \mathbb/\mathbf/\mathcal, \dv/\pdv с порядком, \tag,
  \left\langle и \lfloor/\lceil/\| и т. п., \not, около 80 новых символов и стрелок.
- OMML: m:m (столбцы mcJc), m:eqArr (точки выравнивания m:aln), m:groupChr, limUpp/limLow, f noBar. Чтение обратно в линейную запись.
  MathML: mtable, mover/munder и обратно. В Word и в LibreOffice (нет модуля Math) НЕ проверено.
- Круговой обмен (с 1.3.4 — по-настоящему): все 12 образцов из eqsamples.go после OMML и после MathML дают тот же OMML, что и исходник
  (eq_test.go). До 1.3.4 по собственному eqtest проходили 5 из 12 (OMML) и 3 из 12 (MathML). Что чинили:
  пробелы \, \; \quad (в OMML — U+2009/U+2005/U+2003, в MathML — mspace 0.17/0.28/1em), номер \tag (в OMML — прогон «    (1.3)»,
  в MathML — mspace 1em + mtext), cases из MathML (раньше читался как array), основание ∫ ∑ lim в MathML (раньше {\int}_0 — уже не оператор),
  жирные буквы из MathML, прямые d и ∂ в производных (новая команда \mathup{…}), двойные скобки в EqPlain у {(a+b)}^2.
- Диалог формулы: 7 палитр (шаблоны, матрицы и системы, анализ, греческие, операторы, стрелки и логика, множества), 17 примеров.
  Галочка «Отдельной строкой с номером справа»: центральная и правая табуляции, номер — поле SEQ Формула.

### Названия, перекрёстные ссылки, перечни (captions.go, captions_ui.go)
- Поля: `SEQ <категория> [s] #<id>` (s — номер с главой) и `REF <закладка> l|n|s|p` («Рисунок 1.2», «1.2», «рис. 1.2», «(1.2)»).
  Номера пересчитываются при каждой вёрстке (computeSeq), F9 не нужен. Повторный id после копирования получает новый.
- Глава берётся из заголовка 1: нумерованный списком, «2 …», «Глава 2», «ПРИЛОЖЕНИЕ Б» (буквы по ГОСТ без Ё З Й О Ч Ъ Ы Ь).
  В приложениях нумерация всегда «А.1». Введение и Заключение номера главы не дают.
- Лента «Ссылки → Названия»: «Вставить название» (рисунок под картинкой по центру, таблица над таблицей слева),
  «Перекрёстная ссылка» (Ctrl+щелчок переходит к названию), «Перечень иллюстраций» (область lof:<категория>, обновляется по F9).
- docx: номер главы пишется текстом, счётчик — `SEQ Рисунок \* ARABIC \s 1` (+ `\r 1` у первого номера главы, иначе LibreOffice нумерует сквозняком).
  Закладки: `_RefN` охватывает «Рисунок 1.2», `_RefN_n` — только номер. REF к `_n` — режимы n/s/p (s и p собираются обратно при чтении).
  Перечень — `TOC \h \z \c "Рисунок"`. При чтении номер главы перед SEQ (в т. ч. результат STYLEREF из Word) убирается.
- ODT: text:sequence / text:sequence-ref, перечень — секция TexoraLOF:<категория>. RTF: только готовый текст (поля теряются).
- Проверено: docx и odt — номера и ссылки совпадают после чтения; LibreOffice показывает docx с верными номерами.

## 1.3.2 (07.11.2026): второй отзыв с Windows
- Читалка PDF зависала на книге-скане: кэш расшифрованных картинок держал до 64 штук без учёта размера
  (скан 600 dpi = ~105 МБ в RGB), процесс раздувался до гигабайтов. Теперь: кэш по объёму (200 МБ, вытесняет давние),
  картинки больше 16 Мпикс сразу хранятся уменьшенными (pdfimgfast.go: reduceFactor, shrinkBig), быстрый путь для 1-битных

  CCITT: без map в горячем цикле, строки пишутся сразу в выходной буфер (fillBits). JBIG2 generic: строки с полями, без проверок границ;
  области обрезаются по высоте страницы (j2region.fit, «полосатые» страницы с высотой 0xffffffff). Скан 600 dpi: 0,78 с/151 МБ → 0,32 с/76 МБ на лист.

## 1.4.2 (07.11.2026): векторный PDF, автосохранение без путаницы
### Экспорт в PDF (pdfout.go)
- Тот же PagePainter, что рисует экран, получает вместо холста pdfPage (pp.vec, k = 1 пт): прямоугольники, линии, текст, картинки.
  Поэтому PDF совпадает с экраном и печатью (сверено Poppler-ом на testdata: формулы, обтекание, таблицы, названия).
- Текст — настоящий: шрифты Type0/Identity-H + CIDFontType2, вшиваются урезанными (номера глифов сохраняются, ненужные глифы пустые,
  составные глифы тянут свои части; post сокращён до формата 3). ToUnicode — текст ищется, копируется, его видит Антиплагиат.
  В конце слова пишется настоящий пробел (иначе извлечённый текст склеивается). Буквы, которых нет в шрифте, берутся из запасных:
  Cambria Math, Segoe UI Symbol, Segoe UI, Arial, Times New Roman (на Linux — DejaVu Sans).
- Нет файла жирного или курсивного начертания — дорисовываем: обводка (2 Tr) и наклон 0,21, как GDI.
- Шрифт ищется: на Windows — по таблицам name/OS/2 файлов в %WINDIR%\Fonts и %LOCALAPPDATA%\Microsoft\Windows\Fonts
  (читаются только заголовки; .ttc по номеру), на Linux — та же подстановка, что при вёрстке (Liberation, Carlito…).
  CFF-шрифты (.otf) вшиваются целиком (FontFile3/OpenType).
- Картинки: JPEG как есть (DCTDecode), остальные — Flate, прозрачность — SMask.
- Закладки PDF по заголовкам 1–3 (вложенные, уровни ниже первого свёрнуты), ссылки: внешние — URI, внутренние (#закладка,
  строки оглавления) — переход к абзацу. Заголовок файла — из абзаца стиля «Название».
- Скорость: 425 страниц за 1,2 с, 1,4 МБ. Если векторный экспорт упал, сохраняется прежний PDF картинками с пометкой в строке состояния.
- НЕ проверено на Windows и в Acrobat: поиск шрифтов на настоящей Windows (проверяет тест в CI), дорисованный жирный/курсив на глаз.

### Автосохранение
- Раньше копии назывались по адресу объекта в памяти (у Go адреса между запусками часто совпадают): две открытые Texora
  перезаписывали копии друг друга, вторая при запуске предлагала «восстановить» и стирала копии работающей первой,
  а после сохранения в файл копия вкладки оставалась (удалялся только recover.docx из версий до 1.3).
- Теперь: recover/<pid-время>/<номер>.docx, файл alive обновляется каждую минуту. Предлагаются только копии мёртвых сессий
  (процесса нет или alive старше 3 минут) и плоские копии старых версий. Сохранение в файл удаляет копию вкладки,
  нормальный выход — папку сессии. Восстановленные документы сразу попадают под защиту новой сессии.

## 1.5.0 (08.11.2026): свой интерфейс вместо копии Word
